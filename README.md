## 💻 Cài Đặt & Chạy Cục Bộ (Local Development)

Dự án sử dụng công nghệ Web thuần (HTML/CSS/JS) nên bạn có thể chạy trực tiếp trên bất kỳ trình duyệt nào:

### 1. Clone repository về máy:
```bash
git clone https://github.com/tranduc2204/about_me.git
cd about_me
```

### 2. Chạy với Local Server:

**Sử dụng Python:**
```bash
# Python 3
python -m http.server 8000
```
Sau đó truy cập: `http://localhost:8000`

**Sử dụng VS Code Live Server:**
- Mở thư mục dự án trên VS Code.
- Cài đặt extension **Live Server**.
- Click chuột phải vào `index.html` chọn **"Open with Live Server"**.

**Sử dụng Node.js `serve` hoặc `live-server`:**
```bash
npx serve .
```
